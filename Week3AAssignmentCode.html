Introduction

For this project, I will use the movie rating survey data I collected and implement a Global Baseline Estimate recommender system in R. This method produces solid recommendations using only overall patterns in the ratings, specifically, how a user tends to rate compared to the average, and how a movie tends to be rated compared to the average. The implementation will follow the exact calculation logic provided in the requirements of this assignmnet, but instead of doing it manually in Excel, I’ll reproduce the same steps programmatically in R using the data stored in my Postgres app.

Merge Main Dataframe with calculations as shown in row 25, but instead this calculation will be applied to all the users (surveryed sample).

df_baseline <- movies %>%
  left_join(user_bias %>% select(user_id, user_bias),
            by = "user_id") %>%
  left_join(movie_bias %>% select(movie, movie_bias),
            by = "movie")
df_baseline <- df_baseline %>%
  mutate(predicted_rating = global_mean + user_bias + movie_bias)
